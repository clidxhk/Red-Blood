# 经典小说取材：直接阅读、裁定与原文核对

直接读取用户指定的 TXT，提取有价值的细节，核对原文，对照本书裁定取舍，必要时小批转入创作管线。

工具保持无状态：不登记作品、作者、版本、已抓章节或进度，不生成覆盖率报告、采用计数或复核履历。唯一例外是 `素材/<书名>/取材记录.md` 轻量台账，只记「提过什么、裁成什么、为何」，供跨批次去重。章节范围仍只控制本次读取；原始 TXT 保持只读。

## 命令

```powershell
python scripts/novel_mining.py read <TXT路径> --encoding gb18030 --chapters 1-3
python scripts/novel_mining.py check <TXT路径> --encoding gb18030 --chapters 1-3 --claims <临时素材JSON>
```

省略 `--chapters` 时读取全文。范围按文本中识别到的章回标题顺序临时选取，不建立章节索引文件。无法识别或超出范围时停止，不能声称已抓取完成。编码错误直接报错，不以乱码替换继续处理。

`check` 接收临时 JSON 列表，只需素材本身与证据，不要求书名、作品 ID、章节 ID 或已处理章数：

```json
[
  {
    "target_name": "石灯",
    "category": "器物",
    "attribute": "用途",
    "value": "入夜发光",
    "claim_type": "情节展示",
    "evidence_snippet": "石灯入夜发光"
  }
]
```

证据片段须与所选文本逐字相符。若片段重复出现，另给 `evidence_start`、`evidence_end`，使用本次所选文本内从零开始的 Unicode 码点范围 `[start,end)`。人物说法与传闻必须另给 `speaker`；未知代价、配方和条件不能补造。

工具只输出原文或核对结果，不写文件。临时素材由本轮任务按需组织，用完可清理。核对通过只说明引文存在，不证明归纳正确，更不代表值得建档或设定已获审定。

## 取材流程

1. **读取**：`read` 按需选读章节范围；无法识别或超出范围时停止，不假装已读完。
2. **清单与初判**：每读完一批，先产出素材清单——逐项给出原文名、类别、一句话功能与证据片段，并当场归类：**建档候选／回填既有条目／留作场景细节／舍弃**；舍弃必须写明理由（如「日常器物，无独立法理」）。先归类，后核对，严禁跳过清单直接成文。
3. **核对**：`check` 逐条核对证据片段，不因想建档而放宽逐字要求。
4. **裁定**：先通读该书取材记录，再按名称与功能检索本库既有条目，辨明同名不同物与同物异名。已在册的对象只许回填，不得另开新档；裁定期不写任何正式文件。
5. **过目与小批转译**：素材清单连同裁定结论交用户过目，通过后每批至多 2–3 篇进入根规则的创作管线，逐篇完成检索、成文与适用审校；严禁单批整坨成文。

## 建档门槛

值得建档的判断标准是「撤掉它，本库世界是否缺一块」：须有独立法理、独有功能或历史纵深，方可单独成篇。原文出现频次与名字响亮程度都不是标准。菜刀、板凳一类的日常器物默认留作场景细节或舍弃，除非它在本库世界中确有独立的神异定位。

例：屠夫的杀猪刀在第 1—10 章批已转译为 `世界/器物/九州/解牛刀.md`；第 11—20 章批再遇同一对象，只能回填该条目，不得另开「杀猪刀」新档。

## 转译纪律

只借原型——功能、结构、社会位置与叙事作用；不搬原书专有名词、独有体系与独有宇宙观。「霸体」「灵胎神藏」一类原书自设概念必须拆开处理：骨架（它解决什么问题、占什么生态位）可以借，血肉必须换成根目录法理（形意对流、帝网、业、州城法网、器物六阶等）；本库确无对应法理时，如实告知用户，从最小假设审慎补建，严禁整块移植后伪饰为既有设定。每篇转译方案写明四件事：借什么、扔什么、换成什么、挂在哪条既有条目或法理上。

## 取材记录

`素材/<书名>/取材记录.md` 是取材唯一的跨批次状态：每次提取前先通读，每次裁定后立即更新。逐行记录原文名、裁定（已转译／已回填／场景细节／舍弃／待议）、去向或理由。不记章节进度，不做覆盖统计；已转译条目以仓库实际文件为准，记录只承担索引与警示职责。该目录不属正式内容，双链检查与正式设定检索默认排除。

## 转化时关注什么

先分清原文事实、通用功能与本次原创补完。重点判断境界与代价、资源和量产、身份侦测与战斗平衡，以及地理时代适用范围。名称清楚贴切，避免堆饰和逐篇套用相同的传奇源流、极端反噬及抒情结尾。

生成文件名优先使用已有的自然简称，读起来顺口、看得出是什么即可。不要把产地、材质、功效和形制全部塞进名称；这些信息写入正文。改名时同步标题与引用，不保留一套冗长正名和另一套常用名来增加辨认负担。

日常阅读、取材分析、裁定与工具维护由主代理直接处理；实际撰写正式设定时执行根规则的创作管线。原文核对不能代替仓库检索、清单裁定、正文审校与旧文回填。

验证：`python -m unittest discover -s scripts -p test_novel_mining.py -v`。
