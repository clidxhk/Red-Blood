# 取材流程

读取指定文本 → 产出素材清单并按建档门槛初判 → 核对原文 → 通读取材记录并检索本书裁定 → 用户过目 → 小批创作回填。

1. 用户给定原文，本次按需选读。工具不登记作品、章数、覆盖率或抓取进度。
2. 临时素材只记录要讨论的内容及原文片段；事实、人物说法、传闻和推演分清，不用预写答案冒充提取。
3. 核对片段是否存在，以及是否足以支持归纳。未知字段留空，不因模板要求而补造。
4. 裁定先读 `素材/<书名>/取材记录.md`（含批次索引），再检索本书既有条目：回填现有条目、留作场景细节、值得新建还是舍弃。重在增益，不设数量指标；每次裁定后更新台账，批次结局记入顶部索引，防止下一批重复翻出或重跑同一范围。
5. 裁定清单经用户过目后，每批至多 2–3 篇进入正式创作；此时才按根规则调度创作与适用审校角色，完成必要回填。

工具仅提供无状态读取和引文检查，不建设数据库、来源注册、章节台账、任务调度、审核状态机或长期采集档案；唯一持久状态是上述轻量取材记录。具体命令见 `README.md`。
