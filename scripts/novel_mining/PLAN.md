# 取材流程

按用户要求简化为：读取指定文本 → 提取细节 → 核对原文 → 对照本书 → 必要时创作回填。

1. 用户给定原文，本次按需选读。无需登记作品、章数、覆盖率或抓取进度。
2. 临时素材只记录要讨论的内容及原文片段；事实、人物说法、传闻和推演分清，不用预写答案冒充提取。
3. 核对片段是否存在，以及是否足以支持归纳。未知字段留空，不因模板要求而补造。
4. 主代理直接检索本书，判断是回填现有条目、留作场景细节、值得新建还是舍弃。重在增益，不设数量指标。
5. 真正进入正式正文创作时，才按根规则调度创作与适用审校角色，完成必要回填。

工具仅提供无状态读取和引文检查，不建设数据库、来源注册、章节台账、任务调度、审核状态机或长期采集档案。具体命令见 `README.md`。
