# 茶馆闲聊写作规范（故事/茶馆闲聊目录）

本规范适用于 `故事/茶馆闲聊/` 目录树下全部任务：灯下短论系列回目、`场景/`、`茶馆小人物/` 与 [[茶馆闲聊时间线]]。全仓库通用的文件结构、交叉引用、标签规则见仓库根目录的 `AGENTS.md`；本文件承载茶馆系列的完整类别规范——回目结构、各段职责、段名模板、人物规则与信息边界，撰写与审校均以本文件为准。

## 一、总则

1. 茶馆闲聊不是单纯写几个人坐着说话，而是借一间旧馆、一屋杂客和一场夜谈，把州城里已经发酵的某层世道掰开给读者看。重心有三层：先让读者看见这回夜话是被什么事逼出来的；再让不同阶层、不同位置的人把同一桩事说出不同冷热；最后把闲谈收束成一条更大的世界观线索，接回已有设定。
2. 每回必须清楚回答四问：今夜为何开口、谁在开口、他们各自凭什么这样说、这些话最后照见了什么。
3. 即便写市井闲话，也要自然带出灵脉、丹药、工坊、法器、契券、伤脉、巡符、阵路这类修行秩序，不得滑成只换名词的普通街谈。

## 二、时间线先行，写完回填

1. 续写、补写、插写任何回目之前，必须先核对 [[茶馆闲聊时间线]]，确认本回落在什么时段、接在哪一回之后、属于旧事回看还是近来连线；不得跳过时间线直接起笔。
2. 凡牵涉 [[迅哥]]、[[老舒]]、[[陆照麟]]、[[柳青蘅]]、[[沈相公]]、[[邢五]]、[[周六顺]] 等固定人物，先核对该人物在该时点已经历过什么，尤其先分清迅哥是否仍在备考、是否已断学宫路、是否已出海。
3. 本回若补出新的前后节点、人物转折、外海回讯或州城新压法，收尾时同步回填 [[茶馆闲聊时间线]]，不得让重要先后关系只散落在单篇正文里。

## 三、回目结构：八段与各段职责

回目固定为八部分，正文主体六段。标题可以有文气，但段名必须清楚、稳定、全系列统一，不得一篇一换，不得为求花样牺牲体系感。

### 1. 标题

采用两段式：`系列名 + 回次 + 话题短题`（如 `灯下短论第十九回·雨符`），或 `系列名 + 话题短题`（如 `茶馆闲聊·雨符`）。全系列已稳定使用同一命名法后，不得频繁变体。

### 2. 插入引用

标题下先放 3 至 6 个最关键的交叉引用，优先顺序：本回核心话题 → 最相关的上游设定 → 本回主要出场人物 → 茶馆本身或相关场所。

### 3. 背景概述

只负责回答"今夜为何会聊到这件事"：先一句点明本回夜话围着什么事起，再一两段交代事件压到街面的方式，末尾点出本回真正照见的不只是事件本身，而是哪一层世道。此段必须短而准，不得一开始就把所有结论说尽。

### 4. 核心设定

负责钉清"这一回夜话真正要掰开的，究竟是哪一层世界观问题"：

- 用 2 至 5 条写清本回最关键的设定判断，重点落在秩序、利益、修行资源、阶层处境、观念变化中的一项或几项。
- 语气要像在钉本回骨架，不得写成重复概述的抒情段；要把"街上正在发生什么"往下压一层，说明背后卡着哪条修行秩序、哪类世道病、哪种人间代价。
- 若本回正文要写得散、要让人物多说闲话，此段更不可缺。

### 5. 出场人物

- 栏目只写人物名与身份短语（如"落魄旧文人""北府旧军汉"），不写"负责什么视角""承担什么功能""本回说什么位置"之类的说明；人物在本回的作用、话头分量和叙述职责，全部放进正文自然体现。此为最终口径，撤销早期"栏目可写视角功能与本回承担位置"的旧条款。
- 人物为何在场不得写进本栏目，按入场时机分流：开场时已在馆中，或至少在夜话正式展开前已坐定、站定、避雨、等人、歇脚、喝茶、卖货、借火的，其在场缘由写进"茶馆情状"；夜话中途才进门、掀帘、上楼下楼、送货、换班、避巡、带消息或撞进来的，入场缘由写进正文动作，随门帘、脚步、换班、送货等叙述自然出现。
- 固定分为两组书写：`**熟客X位**：` 与 `**过路客X位**：`，每组下简短条列；不得只列空名字，也不得把人物介绍写成长段小传。
- 可固定关注四类位置：掌柜或馆中人负责稳场收束，熟客承接系列连续性，当事阶层把痛处说实，灰色接口人物把官面、商面或外路逻辑带进来。
- 人物从哪里来、如何沉淀，见第四节。

### 6. 茶馆情状

负责写"今夜这间馆子是什么气"，不是静态装修介绍：

- 写本回特有的气味、声音、潮气、火色、夜色，门外刚发生过什么，馆里来客为何比平时更紧、更杂或更冷，以及哪个细节暗示本回话题已经压进众生日用。
- 开场已在场人物的停留缘由在此段交代。
- 必须让读者一进门就知道，今夜和别夜不同。

### 7. 席间闲谈

正文主段，负责回答"不同人如何把同一件事说出层次"。

- 推荐节奏：先由最贴近事件的人起话；不同阶层顺次接话，把争论推深；中段放一到两个真正把问题掰开的句子；后段由老熟客、掌柜或最冷的人物做一次收束。
- 必须遵守：不得所有人都一样会说；不得句句都像作者议论文；每个人说话都要带着其位置、胆量和生活痕迹。

### 8. 余意

负责回答"这场夜话最后照见了什么"。不是重复总结，而是把本回从一场局部闲谈接回更大的世界观关系，固定包含两层：本回照见的时代病、秩序裂口或民间心气；2 至 3 个最相关的延伸引用。不得只停在"众人聊了一场"。

## 四、人物复用与沉淀

1. 每回起笔前，先从 `茶馆小人物/` 检索能承接本回话题、阶层位置和功能位置的人物，优先复用；只有现有人物确实无法承担该段戏眼时，才允许新增小人物。
2. 新增小人物前，必须逐篇核对现有内容，确认每个相关人物的出场、职责、口吻、关系线和信息来源前后一一对应；不得出现同一位置新旧条目由不同人占位、匿名功能角色与已建人物并存、人物气质前后失配。
3. 会持续出场、承接关系线、在后文反复被提及的人物，必须先建人物卡（`md` 正文 + `json` 底谱）再进正文；只有一闪而过的行脚客商、驼商或纯过场路人才可不立卡直接出场。
4. 本回给既有人物补出的新经历、立场、关系、职责、见闻或其他可沉淀信息，收尾时同步回填对应人物 `md` 正文，不得只留在某一篇闲谈中悬着。
5. 底层熟客的行业根脚必须拉开：矿路夜班、山里工额（如 [[杜火根]]）与城里碎活、脚价漂浮的本地无产脚夫是两套底层结构，不得混到同一个人物身上。

## 五、段名规范与简式模板

固定段名一套，新写条目不得各篇一换：`## 背景概述`、`## 核心设定`、`## 出场人物`、`## 茶馆情状`、正文主段用 `## 席间闲谈`（或 `## 席间杂论`，全系列择一固定）、`## 余意`。旧版兼容名（`## 概述`、`## 茶馆情况`、`## 茶馆闲谈`）仅限既有条目沿用，新写回目不得新旧混用。

简式模板：

```markdown
# [系列标题或回目标题]

[[相关设定一]] [[相关设定二]] [[相关人物一]] [[相关人物二]] [[相关场景]]

## 背景概述

[点明这回夜话围着什么事件而起，并说明这件事真正照见的是哪一层世道]

## 核心设定

[用2至5条或一小段，钉清本回真正要展开的秩序问题、修行规则、阶层处境或观念变化]

## 出场人物

**熟客X位**：

- [人物]——[身份];

**过路客X位**：

- [人物]——[详细的身份];

## 茶馆情状

[写今夜馆中的气味、声响、来客状态、门外风声与不同于平日的紧张感]

## 席间闲谈

[让人物依次起话、接话、驳话，把同一问题从不同阶层和位置掰开]

## 余意

[收束本回夜话的真正意义，并接回相关旧条目]
```

## 六、场景不重样

不得重复使用已有篇目的场景套路、引爆事件、叙事切口与起话方式；外来残物、旧洞府、街头围观、同类争执等现成戏骨，即便主题不同也不得套用。每回必须另找独立的场景、人物入口和冲突来源，落笔前先检索同系列已有条目，主动避开已用过的开场方式、触发事件和争论入口。

## 七、幕后参考与角色可说信息

1. [[历史报告-帝阙的成型]]、东阳选集这类主要写给读者看的总纲、史论、论说或其他场景向文本，默认只可作幕后参考依据，不得直接放进茶馆众人的参考框架、口头引用或自然议论里。
2. 茶馆众人的说法必须立足各自能接触到的街面风声、亲见经历、行当消息、旧闻残片、地方传说与身份所能承受的认知边界，不得把明显超出其日常信息来源的宏观文本端进馆里。
3. 若用户明确要求把某条材料写进茶馆正文，可写入，但必须先做场景内转化——改写成街谈、见闻、旧人回忆、地方传闻或角色能接触到的二手消息，不得像作者注释或背景资料搬运。

## 八、按需伸缩与收尾核对

1. 纯观念收束篇：可弱化"出场人物"，强化"背景概述"与"余意"。
2. 靠单一事件引爆的篇目：可让"茶馆情状"更长一些，把事件余波先压进馆里。
3. 收尾三查：新节点是否已回填 [[茶馆闲聊时间线]]；长期新人物是否已立卡、既有人物的新信息是否已回填人物 `md`；核心引用与行内交叉引用是否齐全合规。
