# 茶馆闲聊写作规范（故事/茶馆闲聊目录）

本规范适用于 `故事/茶馆闲聊/` 目录树下全部任务：灯下短论系列回目、`场景/`、`茶馆小人物/` 与 [[茶馆闲聊时间线]]。全仓库通用的文件结构、交叉引用与标签规则详见根目录 `AGENTS.md`；本文件专门确立茶馆系列的完整类别规范——回目结构、各段职责、段名模板、人物法则与信息边界，撰写与审校均以本规范为唯一准绳。

## 一、总则

1. 茶馆闲聊绝非寻常闲客围坐清谈，而是借由一间风雨旧馆、满堂形色各异的客商与一场深夜围炉长谈，将州城暗流涌动的世态肌理层层剖析展现。其叙事重心包含三重脉络：
   - 先揭示今夜之长谈因何变故激化而起；
   - 再令身处不同阶层、不同行当的茶客，就同一桩事端碰撞出不同的冷暖心境与利害计较；
   - 最终将满堂浮议收束为一条关乎宏大世界观的深层线索，顺畅接驳既有设定。
2. 每回必须清晰解答四项设问：今夜因何开口、何人于此开口、各自凭何种底气与处境作此言论、这番对白最终映照出何等世道。
3. 纵然着墨于市井琐屑，亦须自然渗透灵脉变迁、丹药市价、官坊劳役、法器抵押、契券利息、伤病残脉、巡符盘查与阵路戒备等修行秩序，严禁退化为仅更换若干名词的庸常世俗闲聊。

## 二、时间线先行，写完回填

1. 续写、补写或插写任何回目之前，必须先核查 [[茶馆闲聊时间线]]，确认本回所处之时空节点、紧随于哪次回目之后、系属旧事追溯亦或近况联结；严禁跳过时间线直接落笔起草。
2. 凡涉及 [[迅哥]]、[[老舒]]、[[陆照麟]]、[[柳青蘅]]、[[沈相公]]、[[邢五]]、[[周六顺]] 等固定出场人物，须先核实该角色在此时点所历之境遇，尤须明辨迅哥此刻究系仍在苦读备考、学宫求道已断、抑或已泛舟出海。
3. 本回若增设了新的先后节点、角色转折、外海传讯或州城法令，收尾时必须同步回填修订 [[茶馆闲聊时间线]]，严禁令关键的编年因果仅零散遗落在单篇正文之中。

## 三、回目结构：八段与各段职责

回目体例固定由八部分构成，正文主体涵盖六段。标题当具文采意境，段名则须严谨、稳定且全系列高度统一，严禁各篇随意更迭，切勿为求句式花哨而破坏体系规制。

### 1. 标题
统一采用两段式结构：`系列名 + 回次 + 话题短题`（如 `灯下短论第十九回·雨符`），或 `系列名 + 话题短题`（如 `茶馆闲聊·雨符`）。全系列选定稳定命名法后，严禁无故频繁变造。

### 2. 插入引用
紧随标题与标签之下，依序置入 3–6 个关键交叉引用，推荐优先级：本回核心话题 → 关联最密之上游设定 → 本回核心出场人物 → 茶馆本身或关联处所。

### 3. 背景概述
专司回答“今夜因何会牵涉此事”：先以凝练笔触点出今夜夜话因何变故而起，再以一两段交代该事件波及街巷街坊的态势，末尾点出本回真正映照的并非偶发事端，而是深层的世道顽疾。此段须短促精准，切忌一开篇便将论断全盘道尽。

### 4. 核心设定
负责确立本回夜话真正剖析的世界观深层法理：
- 以 2 至 5 条清晰陈述本回最核心的设定判断，重心落在秩序异变、利益分配、修行资源、阶层处境或人心思变之中；
- 笔调须似梁柱立架，杜绝写成空洞抒情；须将浮于街面的市井现象深入推演一层，阐明背后所受制之修行法则、体制痼疾与人间代价；
- 若本回正文叙事风格偏向散淡生活化，本段更是稳定设定骨架的刚性基石。

### 5. 出场人物
- 仅列出人物姓名与简短身份标注（如“落魄旧文人”、“北府伤退军汉”），不追加“承担何种视角”、“具备何种功能”、“居于何种论调”等说明；人物于本回的作用、言辞分量与叙事职责，全凭正文交锋自然显露。此为最终规约，废止早期允许添加视角说明之条款。
- 人物为何在场严禁写入本栏目，依据入场时机严格分流：
  - 若在开场时已在馆内，或在夜话正式展开前已然就座、歇脚、避雨、品茗、借火，其在场缘由统一归入“茶馆情状”交代；
  - 若在夜话中途方掀帘进门、上下楼梯、送递杂货、轮值换班、避难躲巡或突兀闯入，其入场缘由顺着正文叙事、推门步履自然呈现。
- 格式统一划分为两组条列：`**熟客X位**：` 与 `**过路客X位**：`，每组之下简要罗列；严禁仅列干瘪姓名，亦切勿写成长篇人物小传。
- 重点关注四类典型席位：掌柜或馆中人负责压住场面、引流收束；熟客承接跨回目的连续性；当事阶层将苦涩境遇落到实处；灰色边缘人物将官面隐秘、商道内幕或外路异闻带入堂中。

### 6. 茶馆情状
负责描摹“今夜此间茶馆之气象与氛围”，绝非静态的陈设罗列：
- 细致刻画今夜独有的市井声响、潮湿冷暖、炉火幽明、门外风雨，以及堂内来客为何较往日更为戒备、繁杂或冷清；
- 捕捉能够暗示本回议题已然压迫至百姓寻常起居的生动细节；
- 开场即在馆内之人物，其停留缘由须在此段自然融入；
- 务使读者甫一入篇，即能真切感知今夜氛围与往昔截然不同。

### 7. 席间闲谈
正文之核心主段，负责展现“各色人等如何将同一桩世态剖析出层次”：
- **推荐节奏**：由最切身感受变故之人率先挑起话头；不同阶层顺次接驳，将争端步步推向深处；中途点缀一两句直击世道本质的沉痛之语；尾声由苍老熟客、阅尽千帆的掌柜或神色冷峻之人作定调收束。
- **口吻深度拉开（何以作此言语）**：不仅要区分立场，更须深究各人“何以作此言语”。同一话题落入不同角色口中，必须深刻映射出其身份背负的风险、饭碗生计的顾虑、往昔创伤、视野局限与性情底色（如周六顺身为当差衙役断不敢妄议公事；沈相公既赞革新又惧丢生计；葛保和本能狐疑畏怯；邢五历经戎马而冷眼洞穿“新贵仍染旧疾”；柳青蘅抱持启蒙批判；岑守玄看破世情心境荒凉；程衡生世故厌烦；苦力汉子听闻深中肺腑）。重大群像交锋预演优先探索多子代理真实调度模式，界定各方已知隐秘、根本欲望、胆略分寸与沉默禁区。
- **恪守世俗差序与言语代价**：茶肆对白必须深嵌世俗等级与尊卑位阶。底层小民面对门阀权贵、高阶修士或官差衙役时，断不会轻率当面斥责或毫无遮掩顶撞，多表现为隐忍克制、委婉迂回、借势试探或退让半步后的审慎陈情；唯有久经沙场、流徙异地的退役军汉（如邢五），方能显露硬朗锋芒。严禁底层角色无顾忌挑衅上位者而瓦解世界观秩序压迫感。
- **配角与过路客分寸及进退场因果**：
  - 边缘角色（过路商旅、跑堂伙计、纯过场路人）严禁在话语掌控权、逗留时长、情绪浓度上喧宾夺主，不可冲击固定熟客与核心人物的主导地位；
  - 进门入场、席间停留与离席退场皆须有因果依据：至少须有一两笔交代其因何进堂、此刻因何止步、为何偶然听闻插话、言毕因何驻足或抽身离去；
  - 过路客最稳妥之妙用乃带入外界风声、特殊营生视角或目击见闻，严禁在缺乏铺垫时写成与熟客同等熟稔抗辩之人。
- **既有角色入场因果**：既有角色介入场景必须顺着既定事务脉络、行业动作、人脉纽带或地理空间合理介入，切不可仅因“偶然路过”或“被人随手招呼”便唐突承担核心戏份。
- **纪律红线**：严禁所有人辞令口吻千篇一律；严禁言谈皆如作者代发言论；各人言辞举止必须深深烙印其身份地位、生存顾虑与风霜阅历。

### 8. 余意
负责收束“这场深夜长谈最终照见了天地何等气象”：并非空洞机械的总结，而是将局部的街谈巷议重新接回浩瀚的世界观脉络。固定包含两重视界：
- 本回映照出的时代病灶、秩序裂隙或民间心气；
- 2 至 3 个关联度最深的延伸双链。
绝不可仅仅停留在“众人散去、夜深更息”的浅层收束。

## 四、人物复用与沉淀

1. 每回动笔之前，必须先检索 `茶馆小人物/` 目录，优先复用能够承载本回议题、阶层立场与情节功能的既有人物；唯有现有角色确实无法承担本回戏眼时，方准许增设全新小人物。
2. 新增小人物前，须逐篇核对既有文献，确保人物出场、职司、言谈口吻、人际脉络与见闻来源前后严密呼应；严禁出现同一职司被不同人物重复占位、无名过场与已建档人物混杂、或人物风貌前后割裂等缺陷。
3. 凡具有持续出场价值、承接关键伏线、将在后续篇章中反复现身的人物，必须先行建立完整人物卡（Markdown 正文 + JSON 底谱）方可正式入席；仅一闪而过的行脚客商、驼帮脚夫等纯背景过客，方可免于立卡。
4. 本回若赋予既有人物以全新经历、立场变迁、人际纽带或见闻线索，完稿时必须同步回填更新对应的人物 Markdown 正文，切勿令其悬置于孤立篇章之中。
5. 底层熟客的营生根基必须严谨拉开：矿区夜班、山场苦力（如 [[杜火根]]）与城邑碎工、脚价随行就市的本地揽活脚夫，属于两套截然不同的底层生存结构，严禁混淆于同一人物之上。

## 五、段名规范与简式模板

全系列统一固定段名规范，新建条目严禁自行变造：`## 背景概述`、`## 核心设定`、`## 出场人物`、`## 茶馆情状`、正文主段采用 `## 席间闲谈`（或 `## 席间杂论`，全系列选定后一体保持）、`## 余意`。早期兼容段名仅限旧文沿用，新编回目严禁新旧体例杂糅。

简式模板：

```markdown
# [系列标题或回目标题]

#标签1 #标签2

[[相关设定一]] [[相关设定二]] [[相关人物一]] [[相关人物二]] [[相关场景]]

## 背景概述
[点明今夜夜话因何变故而起，并交代此事究竟映照出哪一层世态]

## 核心设定
[以 2 至 5 条清晰陈述本回展开的法理秩序、修行法则、阶层处境或人心变迁]

## 出场人物

**熟客X位**：
- [人物]——[身份];

**过路客X位**：
- [人物]——[详细身份];

## 茶馆情状
[刻画今夜馆内之气息、声响、茶客神态、门外风雨与深沉的戒备之感]

## 席间闲谈
[众茶客顺次引出话头、辩驳交锋，将同一议题从不同阶层视角剖析展开]

## 余意
[收束本回夜话之深层启示，缝合相关世界观谱系]
```

## 六、场景不重样

严禁机械复用既有篇目的场景套路、触发事端、叙事切口与开篇方式；诸如外来残片、古修洞府、街头骚乱、同类口角等成套叙事模版，纵使主题各异亦不可套用。每回必须开拓独具一格的场景风貌、人物切入点与冲突导火索；落笔前务必检索同系列既有篇目，主动规避已使用过的开局手法、事端诱因与争端切口。

## 七、幕后参考与角色认知边界

1. 《历史报告-帝阙的成型》、东阳选集等主要面向读者展现的世界总纲、通史论赞与思潮考证，默认仅作为创作者幕后推演之底本，严禁直接化为茶肆茶客的认知框架、口头引据或日常议论。
2. 茶馆众人的见识与言辞，必须牢牢扎根于各自所能触及的街巷风声、亲历劳役、行当门道、故老残言及身份地位所决定的认知边界，严禁将明显超越其视界层级的宏大文献生搬硬套进茶肆对白。
3. 若用户明确要求将某项历史或法理材料融入茶馆正文，必须先完成场景化、人文化转译——改写为街谈风声、宿老追忆、行商传闻或角色所能接触到的传言，绝不可呈现为作者批注或背景资料搬运。

## 八、篇幅伸缩与收尾核验

1. **观念收束专篇**：可适当简化“出场人物”之波澜，重点深耕“背景概述”与“余意”之哲思。
2. **单一事件引爆篇**：可扩充“茶馆情状”之篇幅，令变故余波与窒息气浪先行浸透茶堂。
3. **收尾三项严查**：
   - 全新编年节点是否已回填修订 [[茶馆闲聊时间线]]；
   - 长期活跃之新角色是否已规范立卡，既有角色之新线索是否已同步回填至对应 Markdown 正文；
   - 核心交叉引用与正文行内双链是否逐字精确、齐备合规。
