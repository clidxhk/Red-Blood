# 季风双湾铁帆潮

#州郡 #梵陆 #地理

[[梵陆之地总录]] [[白界商行]] [[娑罗海帮]] [[衡皇远航]] [[香风诸埠]]

## 概述

[[南岬热港]] 镶在 [[梵陆之地总录]] 最南端，北靠 [[炽原]] 东西两翼陡峭的赤石山崖，南面挟着漫山胡椒藤与椰林直插滚烫蔚蓝的西洋大海。海岸西头挑着直面远西大洋的象牙岬，东头弯出吞吐西洋帆影的娑罗湾；千百年来咸腥海风里飘荡的是丁香、肉桂、檀木与晾晒海鱼的浓香，近几十年港湾高处竖起冷硬刺眼的白色符文石塔后，风里又混进了散不去的火药硝烟与铁炮油脂味。

## 疆域梁柱与山川形胜

[[南岬热港]] 背靠 [[炽原]] 数百丈高的迎风断崖，面朝浩瀚无垠的西洋季风海，陆地纵深最窄处不足三十里，最宽的河口三角滩也不过百余里，地形宛如两条挂在高原衣摆上的翠绿丝带。

西岸受大洋巨浪正面冲刷，山崖直插深海，水深浪急，天然凿出象牙岬、白礁澳等几处可泊吃水数丈巨舰的深水良港，出了海门趁东北季风西去，便可一路远通神族治下的 [[雾锚州]] 与 [[炽岬州]]。东岸地势较为平缓，泥沙与珊瑚礁围出风平浪静的娑罗湾与大片红树林泻湖，帆船出了湾口乘西南季风东去，十数日便可直抵海峡咽喉 [[香风诸埠]]，再折向东北更能深入 [[南溟珠群]]。

东西两岸一路南延至大陆尽头的乱流岬，两洋暖流在此迎头对撞，海面终年翻滚着雪白浪花与暗礁漩涡。每当海季转换，乌黑台风裹着暴雨扑上岸来，碗口粗的椰树被吹得弯腰贴地，唯有深湾内港的铁链浮桥与石筑防波堤能护住满港商船。

## 灵脉要塞与神庙关防

从 [[炽原]] 断崖倾泻入海的几十条短促山溪，携带着山中金火余脉一头撞上大洋澎湃的水行潮气，在各处海岬湾口结成灵气活络却躁动难安的水火交汇眼。

早年海防全靠本土土王与大庙分守。临海椰林高崖上至今立着好几座被海风蚀得斑驳的石砌海神庙，港湾老码头旁还竖着一方青石古海碑——依 [[圣皇纪元编年]] 所载，那是第十二纪元寒衡纪 [[12.衡皇]] 推行 [[衡皇远航]] 时，九州镇海官船停泊互市留下的界刻。老城一侧的土王水寨则用铁木巨桩与红石垒起挡潮矮墙，墙头架着发射火油罐的旧式床弩。

如今真正锁死双湾咽喉的，却是 [[白界商行]] 在临海滩涂上新建的星角炮台与符文白塔。白塔以神族冷白石料混入定序符文砌成，高耸于椰林之上，塔顶日夜流转着刺破海雾的冷白光束，与港门两侧数十门校准潮道的冷铁重炮遥相呼应；[[娑罗海帮]] 的大船坞则退守内湾深处，靠连片铁木水栅与船头辟水护阵自保，三家防线犬牙交错，炮口暗地里谁也没少瞄着谁。

## 诸邦治所与法度规制

走在象牙岬或娑罗湾的街头，不出五里路便要连换三套截然相反的王法，堪称全梵陆秩序最割裂的怪胎之地。

临海最宽敞平整的滩涂地段，是被铁丝网与白石界桩圈起来的 [[白界商行]] 租界。界内街道笔直，设契约账房、平码货栈与验契公堂，压根不认本土大庙的 [[净秽戒律]] 与 [[贝叶经禁]]，一切买卖词讼只认 [[苍穹圣廷]] 通行的标准银币与白纸黑字的契约文书。

紧挨租界铁丝网往里，便是沿海几个 [[象王诸邦]] 小土王的老城治所。老城依旧死守四层净秽老规矩，石庙、王宅、彩布香市与城外臭泥棚界限森严；只是这些土王为了向商行赊购火炮打内战，早已把老城的海关抽税权抵给了神族账房，城门税吏收上来的银钱还没捂热，就得先抬进租界点验扣息。

老城另一侧延伸进水面的成片高脚木桩栈桥，则归 [[娑罗海帮]] 各大船头按船规弹压。再往双湾外围钻进密不透风的红树林暗港与珊瑚礁汊口，三家法度便统统失灵，走私快船借着涨潮夜色进出如梭。更教老城贵族咬牙切齿的是，每逢入夜，总有成批从内地毒矿与泥棚逃出来的年轻 [[承垢]] 泅过臭水河，一头扎进租界募兵棚按手印领火铳；码头苦力间还常传言，有个驼背赤脚、满头白发的老脚夫（实为敛迹尘世的 [[5.无座行者]] 凡相之一）常在三界交接处替人扛香料包，无论走过净祝石阶还是神族岗哨，竟从未有人拦得住他。

## 豪强宗门与地方道统

海风吹来的暴利与火药，把四方过江猛龙全聚到了这条窄窄的海岸线上。

势头最凶的是楔入双湾的 [[白界商行]]。商行总督与驻港 [[神裔]] 掌柜背靠远洋炮舰，左手放军贷拉拢沿海土王，右手招揽买办与火铳兵，短短数十年便把双湾最肥的深水泊位与香料定价权攥进了掌心。

本土根基最深的是世代跑海的 [[娑罗海帮]]。这群排在净秽第三等的市商大族手里握着上百艘铁木大帆船与内陆收购网，眼下却被挤在神族铁船与内地土王之间左右受气，帮内船头为投靠租界当买办还是暗走私路自救吵得不可开交。

山坡上的沿海小象王们一面靠神族火器互殴抢港，一面还得供养城里的海庙净祝装点门面；至于海崖石窟间，也常有从 [[炽原]] 南下云游的 [[苦行林]] 火修驻足，受海商重金礼聘登船护航，拿一身滚烫炽息替香料船驱散深海妖鱼。

## 物产岁贡与民俗生息

[[南岬热港]] 遍地是海上豪商抢破头的香货重宝。背山坡地盛产颗粒饱满的黑胡椒、紫肉桂、丁香与百年老檀香木，沿海织坊出产掺有灵蚕丝的细棉灵布，西岸密林更有驯熟的健壮灵象与成对雪白巨牙，外加珊瑚礁下采出的南海夜光螺与药贝，船舱装满一趟拉回东海或远西皆是十倍厚利。

早年第十二纪元 [[衡皇远航]] 船队泊港互市那会儿，东岸娑罗湾的民间小摊还习惯抓一把莹白货贝找零计价，大宗交割则用金砂、异香与巨牙换取九州官船运来的丝绸、青瓷与精铁器皿。自打九州锁海撤船、神族商船东来，印着圣廷徽记的足色银币迅速冲垮了昔日贝币，只有偏僻渔村的赌摊上还能见到几串磨得发亮的老货贝。

港口百姓的生计全系在 [[季风岁时]] 的风向旗上。每年旱季东北风起，帆船顺风西去；雨季将歇、海面风浪初平的开港吉日，老城与木桩码头万众倾巢而出，船工往海里泼洒香料甜酒、敲响铜鼓拉起拦港铁链，千帆争先恐后抢潮出湾。只是如今立在潮头最显眼处的，早已换成了挂着冷白硬帆、船舷黑洞洞伸出成排铁炮的神族大舰。
