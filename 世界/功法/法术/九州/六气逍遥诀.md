## 概述

[[六气逍遥诀]]为九州流传极古、绝少录入宗门典藏的风游心法与虚空御行之术。世间寻常遁术，如军旅漕运通行的[[扶摇诀]]，多乘山川厚重对流以负重凌虚、裂障排空；亦有别家法门燃精耗气以催烈火，或割裂虚空以强行挪移，多凭霸力撼动周虚。此诀则截然相反，不立威福，不建山门，亦不求撕天裂地之死力。行此诀者，视九重霄汉为无垠洪流，以自身微躯化作游尘，因应天地间清浊厚薄、温寒晦明之随时升降，借气乘风，随波而行。

天地不仁，浩气长存。修士运转[[六气逍遥诀]]时，身躯与周遭气流宛若浑然一体，不仅遁行无迹、御虚极远，更因其不借外势、不存自私之念，得以绝迹于因果罗网之外。凡[[帝网]]所布之律则符线、诸般[[业]]火因缘，遇此“不落名实”之空灵身相，皆如网捞微风，无从系缚。

## 核心设定

[[六气逍遥诀]]立基于四道玄要法则，凡违逆其中一者，气机立散：

1. **乘正御辩**：天地有大正之气，四季有阴、阳、风、雨、晦、明之六化。行者不强逆天候，顺四时之变以调息，御六气之偏以济身，借温差为升降之机，借气脉之流向作腾跃之足。
2. **无待无羁**：天下之能御虚者，或待巨翼，或待灵剑，或待云舆，终有可穷之时；此诀讲求“无所待”，不依兵刃符器，不恋灵山福地，凡心有驻留，身即滞涩。
3. **体同游尘**：“野马也，尘埃也，生物之以息相吹也。”修行者须化去执相，将体魄气血视作天地喘息间一粒浮沫，风来则起，风止则憩，无强横对撞之虞。
4. **意不妄取**：吞吐大千而不囤积私藏。行途借力万丈罡风，过体即还于太虚，体内清流如长川注海，不住不聚，免受[[业]]力与气毒积滞之扰。

## 法统源流

此诀上承[[道圣-石朴]]“道法自然、去锋存生、不入帝网”之至理，相传上古大劫之前，有旷达古仙散居于大泽绝岭之间，常年端坐悬崖绝壁，仰观大荒巨禽凌云、秋蝉蜕壳之态，悟天地浩气对流之变，遂成此法。其法理与[[观测法]]暗通，皆守“只观不妄动、存照不争锋”之默照，不载于官修仙籍正律，亦无祖师金身受世人供奉。

及至[[7.律皇]]定律、各方宗门林立之际，各派宗师因其“不可庇护家业、无法筑台结阵”，斥其为散修野道避世之私术，远不如[[扶摇诀]]之便于行商聚兵，亦不如[[浩然正气诀]]之能理契鸣城。然而数度天地更迭、仙阙倾颓之期，大宗巨族皆随因果崩解而湮灭，唯有隐修草泽的持诀修士，化形风烟，远遁云海深处。零星法诀残卷多刻于危峰风穴石壁，或以蝇头细字录于残破绢帛，在落拓野修间代代隐秘承传。

## 修炼总纲

修习本诀，不拘泥于特定时辰灵穴，全在感通天地呼吸，凡分五重节次：

```mermaid
flowchart LR
    A["观尘"] --> B["候息"]
    B --> C["辨气"]
    C --> D["抟虚"]
    D --> E["还风"]
```

1. **观尘**：置身密室或晨曦林中，屏息凝神，目视阳光下一线浮尘翻卷，悟万物受气推荡而动之微理。
2. **候息**：登高临风，解开袍襟，以周身毛孔迎向山岚；体会气浪拍击身前身侧之冷暖，探知气团聚散之先兆。
3. **辨气**：引阴阳、风雨、晦明六类天候之气入周天，不炼为己有，仅以意念标记其流向、厚重与轻灵之差。
4. **抟虚**：足踏罡煞相交之缝隙，身躯微侧，借气机高下厚薄之隙空旋拔起，如同陀螺离地，不起狂澜而自升百丈。
5. **还风**：法力耗尽或势尽欲落时，不施硬抗之力，顺坠势吐纳，将周身余劲悉数归还周虚，轻如鹅毛着地，不留半分足印。

## 入门条件与修持代价

### 适修之人
心性萧散、不汲汲于功名尊荣者；天生对温差、气鸣、云影变换敏锐至极的清拔之士；散修中飘蓬无依、无家室牵累之人。

### 难成之人
性情重利、执着于宗族传承与道场霸权者；长年依赖厚重法宝抵御攻伐之辈；法力滞重雄浑、惯以千钧之力压制敌手的修士。此等修士心神多挂碍，稍入罡风，心魔立起，极易失坠。

### 修持代价
- **离群孤寂**：长年游走于重霄之上，目之所及皆是浮云万里与凄寒冰屑，极少沾染人间烟火，凡情俗念渐趋淡漠。
- **罡风蚀体**：九天罡风凛冽胜如刀割，初境修士肌表常被冻裂剥离，须以漫长时日令气机与寒煞共融，久而久之体温较常人更冷三分。
- **无阵可守**：此心法排斥一切固化灵脉之阵势，行者无法久居封闭洞府，一旦固步自封，灵觉便随之枯竭，难以庇护门人族类。

## 逍遥六阶

[[六气逍遥诀]]配合[[修士境界]]之递进，分为六层递进之境，每上一层，形骸与天地之隔便融消一分：

### 第一阶：候息阶（对应炼气期）
* **感官蜕变**：耳窍通微，可辨十丈内草叶摇曳之风势；阖目能知东南西北气流缓急。
* **显化能力**：踏风轻灵，奔行于草尖沼泽而不沉，可借一阵斜风跃起三五丈，身轻如絮。
* **修行窒碍**：肉体凡胎尚畏严寒，离地十丈便感气促神疲，不可久滞空中。
* **外相趋向**：身形日渐瘦削清癯，衣袂飘动间几无风声，行步落足无尘。

### 第二阶：辨气阶（对应筑基期）
* **感官蜕变**：察觉天地六气（阴阳冷暖、晦明聚散）之流转轨道，眼帘隐现淡青色气漩。
* **显化能力**：施展“御辩步”，在两道冷暖交汇的气压之间游走，不御飞剑亦能凭虚滑行百里，滑空无痕。
* **修行窒碍**：遇狂暴雷云或暴烈火煞时，六气混杂，容易扰乱体内回环，迫使修士迫降。
* **外相趋向**：呼吸极度细长沉静，一呼一吸常越数十息，言谈声调平缓幽远。

### 第三阶：凌罡阶（对应金丹期）
* **感官蜕变**：灵觉透出百丈，能直觉感知千丈高空上重重罡风断层之“风眼”与“空穴”。
* **显化能力**：乘风破云，直上千丈碧霄。可在暴风骤雨之中如游鱼戏水，借助天地暴乱之气作为推力，瞬息千里。
* **修行窒碍**：体内金丹气机容易与九天寒煞产生激荡，须时刻保持心平如镜，不可起争胜杀伐之暴念。
* **外相趋向**：双瞳清亮深幽，发丝偶有微风自绕，常喜登高凭栏，久望虚空。

### 第四阶：扶摇阶（对应元婴期至洞虚期）
* **感官蜕变**：感知扩及百里山川之气流涌动，能借江海蒸腾之水气与山脉推挤之气流，洞悉大地呼吸；洞虚神识洞彻云天经纬，足踏极薄风隙。
* **显化能力**：身如巨鹏化形，展臂即生大息回流，抟扶摇而上九万里，直入九重天外云海之上，昼夜飞渡数大州。
* **修行窒碍**：九天高处寒冷绝伦，更伴有天外罡煞乱光，若元神纯度不足，易被虚空寒流冻结神念。
* **外相趋向**：周身气息近乎透明，于万丈高空中盘坐，周身三尺罡风自行避让分流。

### 第五阶：游无穷阶（对应化神期至合体期）
* **感官蜕变**：跳脱肉眼与寻常神识之拘囿，以虚神洞照感应九天与太虚星纬之牵引吞吐，视天地界膜如薄绢。
* **显化能力**：身随意转，穿梭于诸般绝地虚空断层之间。不击碎空间，而是顺着虚空裂隙的气流缝隙自然滑移，遁速超拔现世法器之上。
* **修行窒碍**：与大虚同化越深，世俗记忆与宗族情感越发淡薄，稍有不慎即会化作天地长风，神魂散尽而道化。
* **外相趋向**：行止如幽灵虚影，立于闹市人群之中，旁人极难注视其确切面目，转瞬即忘。

### 第六阶：无待归虚阶（对应渡劫期至大乘期）
* **感官蜕变**：无内无外，自身即为天地六气之显化，彻底断绝主客之辨。
* **显化能力**：身入太虚，不依赖灵气、光亮、空间乃至时间之推动。“乘天地之正，而御六气之辩，以游无穷”。九州之内，无一禁制大阵可拦，无一[[帝网]]因果可系。
* **修行窒碍**：此境已涉造化玄关，非世间笔墨所能定格，若心底尚存半分“我为修士”之分别心，立从极境跌落。
* **外相趋向**：宛若天地间一缕无形无质之浩气，来去无拘，声名尽泯，非大知者不能遇。

## 术法与仪轨

### 日常课业：野马观息课
每日破晓破暮、阴阳割裂之际，行者须端坐于绝壁石梁之巅，宽衣解带，放开心神。任由冰凉晨雾或炙热晚霞自皮肤渗过，不运转防御法罩，纯以自身气机呼吸吞吐温差。此课旨在消磨肉体对外界天候的抵抗执念，化“相抗”为“相容”。

### 御辩步
应对斗战挪移之核心身法。足不着地，凭借交战双方兵刃碰撞、法术炸裂激荡出的气流涟漪而行。敌方攻势越刚猛、掀起风浪越暴烈，修行者脚下借力越充沛。看似险象环生，每每擦刃而过，实则在气浪推荡下自然滑开，不耗己身分毫元气。

```
敌势进（烈风骤发） ──> 气浪推荡身相 ──> 借旋流侧滑 ──> 刃过而身飘然
```

### 扶摇抟升术
登临九重天之拔升大术。行者双足微扣，意沉气海，周身穴窍吞吐极冷与极热两股对流，自身化作狂暴风眼。旋转之间，平地卷起接天飓风，将修士平稳托送至数万丈绝高之天幕，瞬息摆脱地面追杀与群敌包围。

### 大息借行法
长途远遁之根本法门。九州大地，山河绵延数千万里，地热与寒洋时刻产生横贯大地的浩瀚风带。行者展开双臂如巨鹏舒翼，将神魂沉入万丈高空的定常气流，不鼓动法力，全凭天地大息自然推移，日行万里而气海充盈如初。

### 虚舟避网式
专门规避天穹[[帝网]]勘探、因果锁链追踪之极密仪轨。修士将元神收缩归于无何有之乡，体表灵光悉数湮灭，法力波动平伏如镜，使自身气机同化为普通气流扰动。当[[帝网]]金线扫掠而过，行者恰似一叶空舟飘荡于浩淼波涛之上，网眼漏风，不沾因果，不录名籍。

## 心法思想

本诀极重意旨，所谓“法随心转，意滞身沉”。心法承袭古仙精髓，直指修道终极真意：

> **至人无己，神人无功，圣人无名。**

* **无己故不积因**：凡被世间杀阵、法宝索命者，皆因“己身”固若顽石，与天地万象对立排斥。行者视肉身为寄宿于虚空的逆旅，身同天地之游尘，自无仇隙因由可寻。
* **无功故不承负**：世俗修士立不世之勋、占名山福地、掠天下气运，皆引无边[[业]]力纠缠反扑；逍遥修者不争寸土，过眼繁华如烟云，无恩于天，亦无欠于地，因而不负重压。
* **无名故不入网**：天理森严，[[帝网]]以律法名籍、誓愿果报罗织诸界神佛妖魔。逍遥者游于方外，姓名不登青册，面目隐于云岚，无待无求，天地虽巨，亦无法为之立枷锁。

## 历史演变

上古之时，山野多有游仙行此道，朝饮沆瀣，夕宿苍梧，天地清宁。

及至中古大世，宗阀蜂起，[[玄黄内经]]所记诸宗定九州仙律，编纂群生名录以统摄气运。[[7.律皇]]治下有司曾数度遣巨舟、发符兵围猎修行逍遥诀之散修，图谋夺其真经，将此遁法改造为军伍神速之秘技。然而无论如何剥离参研，录入青简之诀要皆化为枯槁死法，凡受军律约束、心怀杀伐执念者修之，必在离地千丈之际爆体坠亡。有司遂毁弃残卷，于仙录中注其为“荒诞无稽之野狐遁”。

大劫频发之岁，天倾地陷，九州生灵涂炭，诸多名门巨室因因果牵连举族覆灭。唯有数名修持六气真诀的落拓闲人，以一具瘦骨承载数卷残书，负于背囊，随天地倒卷之狂风扶摇直上，穿行于碎裂虚空边缘，将上古残余的道统薪火悄然播散于荒海之外。

## 反噬与破绽

[[六气逍遥诀]]虽神妙超然，绝尘离网，亦有不可违逆之天道禁忌：

* **逆风滞气之险**：在灵气干涸寂灭之地、或绝对禁锢封锁的气脉死局中，虚空无呼吸对流，此诀之威能便减损大半，须全凭肉身横渡。
* **不可立势**：修习此诀者终不可聚拢地脉开宗立派，亦无法统御军阵。凡心头升起半分立威作福、划分疆土之执念，周天清灵之气立化铅汞，遁速暴跌。
* **不可结厚阵**：行者若藏身于层层防御法阵之内，隔绝风息与天地寒暖，灵台即刻昏昧，无法借大息飞腾。
* **心念一滞当场坠风**：乘风万里全凭心境空灵无滞。若在万仞绝顶飞渡之时，心头偶生恐惧、贪恋、怨憎等重浊情绪，与天地大息之谐振立断，身躯自重千钧，当即如陨星般直坠重渊，粉身碎骨。

## 结语

六气循环，终古不息；天地有正，游者无穷。

世人汲汲于争一城一地之荣辱、筑万载不灭之金身，终难逃[[帝网]]森罗与万劫共[[业]]之磨洗。唯有洞明小大之辩、拂衣弃去待借之物者，方能在九重天幕之外，乘天风呼啸而过，视人间万象如尘埃野马之相吹。身无长物，名不入册，泛若不系之舟，独往独来于六合之间，是谓真逍遥。
