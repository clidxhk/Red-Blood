# 草木条目写作规范（草木目录）

本规范适用于 `草木/九州/`、`草木/神族/` 及本目录树下全部草木、灵植、异木、药材与生克灵草条目。全仓库通用的文件结构、交叉引用与标签规则详见根目录 `AGENTS.md`，本文件专门确立草木类别的增量专属约束与强制审校基准。

---

## 核心原则：草木首先是“生”

本项目的草木，绝非网络小说中常见的寻常“吞服即破境的数值经验包”、“野外随采随用的回血红药”或“专供主角机缘跨阶的附庸道具”。

草木拥有一整套深植于天地风土、吐纳四时气机、涵养地脉水泉、抵御天地灾变、结连百虫异类、历经采伐炮制乃至受命于神权规训的完整生态与文明历程。它与特定界域的水土性质、王朝与宗门的经济榷禁、仙官与凡民的阶级壁垒，以及九州与神族的秩序之争紧密咬合。

撰写草木条目时，笔力重心绝非简单罗列其能增长几百年道行或提升几成破境几率，而在于深刻回答：
1. **它依凭何种天地造化与方土水泉而滋养生发**；
2. **它的真性气味、四时生克与寒温造化如何运转**；
3. **采摘、炮制与服饵它索取了何等沉重的地脉或肉身代价**；
4. **它如何卷入人道秩序、生民活命、商路争夺与神权定序的文明博弈**。

一株草木若脱离了天地水土与时代秩序，沦为仅凭数值驱使、脱离生态肌理便无法立足的单薄工具，则绝不具备独立立条的资格。

## 九州草木与神族草木的本质分野

草木目录下存在两套截然不同的文明孕育与利用逻辑，动笔前必须先判明其归属与法理底色：

### 1. 九州草木：生于大荒造化、身土不二与因形存真
- **造化本源**：源自大荒山川地脉自然吐纳，受四时风雨、雷击地泉、岁月侵寻而生，深契《[[大荒山川图经]]》与《[[九野本草品汇图经]]》之旨。
- **精神内核**：
  - **身土不二**：万物各得其土，离其本乡则性味骤变；草木真性与山河地脉同频共振，顺应四时盛衰，绝非无根之水。
  - **存真破序**：草木各具寒温燥湿之自性，路旁蓬蒿若得其用可解万民之疫，万年琼芝违逆物性服之亦如鸩毒；坚决打破云端仙家虚抬品阶、神化药效以谋暴利的垄断神话。
  - **生克相资**：孤阴不生，独阳不长。大荒灵植常与异兽灵虫伴生互利，剧毒之处三步之内必有相克相解之草，体现自然法则的深沉自洽。
- **材质与感官**：老根盘错、青苔古润、苦辛回甘、山岚露冷；触手温润粗粝，伴随破土微腥、地泉湿气与苦冽草木清气。
- **代表取向**：雷击木、深渊石藓、荒原救急草、地脉九叶芝、伴妖灵藤。

### 2. 神族草木：生于神庭定序、天弧序列与役法催熟
- **造化本源**：源自镜穹文明的人造巨构与天弧漂流序列，是神族统治机器对自然生命实施技术化改良、制度化定序与高压榨取的规训产物。
- **精神内核**：
  - **剥土定序**：彻底斩断植物对大荒泥土的本能依存，以冷光、符液与灵石基质强行培植；削其野性杂质，使其生长周期严格按工令推进。
  - **列籍配额**：凡所培育之种，皆被编入《[[序名书]]》与天庭官籍，按品秩供给白署、军需或权贵，成为巩固阶序的垄断资本与赏赐筹码。
  - **役法渗透**：通过强力催熟与掠夺性抽调地气，换取纯净无垢的效用，背后则是对土壤生机的大肆透支与对殖地花农的残酷压榨（如花妖、殖地花会体系）。
- **材质与感官**：冷白莹光、银丝叶脉、剔透晶髓、无菌清气；触手冷脆微震，伴随金属微颤与规整剔透的人造冷冽感。
- **代表取向**：神苑白莲、天弧宿种、改序玉参、汲灵官竹、殖地异芳。

## 严禁触碰的文风红线与口癖清单

为杜绝草木条目滑向现代植物百科、科幻杂糅或网络玄幻俗套，全体撰写引擎与审校子代理必须严守以下禁令：

### 1. 严禁现代植物学与生化生理术语侵蚀古风
- 坚决杜绝出现：“光合作用”、“叶绿素”、“维管束”、“基因变异”、“催化剂”、“细胞分裂”、“杂交育种”、“生物活性成分”等词汇。
- **正向规范**：统一置换为古典仙侠与天地气机意象，如“感召朝暾”、“引纳地髓”、“四时荣枯”、“天地气交之异变”、“造化滋养”、“精粹凝质”。

### 2. 严禁游戏数值化与网文进阶行话
- 坚决杜绝出现：“服之增加一千年修为”、“突破几率提升四成”、“暴击率”、“回蓝灵液”、“瞬间回满气血”、“经验包”等词汇。
- **正向规范**：置换为修仙世界的法理与气机描写，如“涤荡经脉阴翳”、“稳固金丹真火”、“借其醇厚地气叩问关隘”、“补益亏损血元”。

### 3. 严禁空洞堆砌“天地灵根、万古唯一”
- 杜绝脱离生长环境与因果脉络的浮泛夸张。草木之珍贵，贵在其夺造化之难、采撷之险、守候之苦，而非空喊口号。

### 4. 严禁滥用口癖垫字与万能词
- 严格遵循根目录 `AGENTS.md` 禁令，杜绝滥用“后世”、“故而”、“论及”、“若说”等高频垫字，严禁机械堆砌“旧X”与万能“压”字。

## 六个必答核心问题

一篇合格立得住的草木条目，必须在正文中完整交代以下六大维度：

1. **本体形态与生长法理**：生于何方水土（绝壁、幽渊、雷击焦土、神苑玉池）？根茎叶花果实形态有何神异？在四时流转之中如何荣枯呼吸？
2. **气味性味与生克本真**：其气味何如？归于寒、热、温、凉何等气性？具苦、辛、甘、酸、咸何种滋味？入炉入药有何生克制化之规矩？
3. **天地依存与生态位阶**：其与周遭山川灵气、凡俗植被是滋养互荣还是霸道吞噬？是否与特定异类灵兽、蜂蝶毒虫形成伴生宿命？
4. **采掘法度与反噬代价**：采撷有何讲究与凶险（如金器伤其性、月夜失其魂、需以玉刃断茎）？采掘是否引发地脉塌陷？过度服饵会否沉积火毒煞气或断绝子嗣？
5. **历史脉络与世道博弈**：它在哪个历史节点或重大变故中显现（如大疫荒年、宗门夺矿、王朝榷药）？曾被仙官丹阁如何封锁？又被草泽医道如何便宜救急？
6. **世界观不可替代性**：其独特性必须从法理与文明渊源中自然生长。它究竟是印证了天地自然的生生不息，还是控诉了人造神权的贪婪规训？

## 建议结构

单篇草木立条时，统一规划以下章节（通用头部格式详见根目录 `AGENTS.md`）：

- **标题与核心交叉引用**
- **概述**：凝练且富有画面感的核心描述，交代草木本质与位阶。
- **核心设定**：阐明其生长法则、性味生克与底层法理逻辑。
- **形态与生长之所**：根茎叶实之神异外观、栖居之方土水泉与感官体验。
- **四时生化与天地依存**：一年四季之气象变迁、伴生之异类生灵与生态链条。
- **采掘法度与炮制之制**：采摘规矩、用器讲究、保存之法与违逆之代价。
- **药用真能与反噬警戒**：救急或炼丹之真效、误用燥烈之毒性与肉身神魂反噬。
- **世道流转与历史位置**：卷入之王朝宗门争夺、丹阁神庭封锁或民间救济历史。

## 与其他类别的联动原则

1. **与 `器物` 联动**：草木为炼制绝品法宝（如灵木飞剑、药鼎柴薪）或编纂典籍（如《[[九野本草品汇图经]]》）之源头；炼制出的成品丹药则与丹道器物紧密咬合。
2. **与 `异类` 联动**：灵草常有通灵化形者，或有绝世凶兽盘踞守护；若草木完全蜕化出独立意志与反抗秩序之抉择，应审慎研判是否升格转录至 `异类`（如花妖、藤怪）。
3. **与 `经济` 联动**：名贵草木必牵涉府库配额、黑市暗盘与玄金市价，应主动与 [《经济/丹药价格.md》](file:///d:/Github/Red-Blood/经济/丹药价格.md) 及商贸条目构建双链。
4. **与 `州郡` / `禁地` 联动**：草木生于方土，必须明确标定其主要产地所属之州郡地脉或绝地禁区，不可凭空悬置。
