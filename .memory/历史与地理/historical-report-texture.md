规则：撰写与修订九州历史报告、王朝兴亡、起义与制度考述时，必须遵从以下三大核心法则：

1. **司马迁风格白话文（文风基准）**：
   - 宗承太史公“究天人之际，通古今之变，成一家之言”与“不虚美，不隐恶，故谓之实录”的史家风骨。
   - 必须是**通俗晓畅的白话文**，但文字须苍劲雄浑、简劲有力，重在人物行迹、言辞神态、时势转折、利害权变与悲壮抉择。叙事要有起承转合、波澜起伏，严禁写成干燥的材料罗列。
   - 篇末以“太史公曰 / 撰者曰 / 考者曰”作点睛论赞，寄寓褒贬与深沉慨叹，融历史经验于一家之言。

2. **坚决剔除“口癖与套话”**：
   - 严禁高频叙述垫字：“后世”（动辄跳出时空下定论）、“故而”（机械交代因果）、“论及”（说明文/论文解说腔）、“若说”（说书套路假定）。
   - 严禁生硬器官化堆叠：“骨/脉/肉”（如“州骨、工脉、军骨”等）。
   - 严禁绝对化句式：“最冷/最硬/最怕”。

3. **坚决剔除现代学术与政论腔（“其它的内容”）**：
   - 严禁使用现代社科理论术语，如“阶级分析”、“阶级断裂”、“半生产半军事阶级”、“生产力/生产关系”、“剥削”、“纯经济之物/纯经济单位”、“总危机”、“系统崩溃”、“组织度”、“线性加深”、“历史的吊诡”、“划时代意义”、“证明了以下几点：第一/第二/第三”等现代词汇与论文八股框架。
   - 历史事件的动力机制必须完全转化为仙侠世界观的原生人事逻辑：灵田课租、矿丁徭役、灵脉被抽取耗竭、豪强门阀庇护兼并、散修黔首流离失所、法网严苛与失期当斩、天灾与中枢失信等天地人事之间的真实利害。

**原因：** 用户明确指出历史报告必须遵从司马迁风格白话文，严厉指出当前文本中夹杂了口癖（后世/故而/论及/若说）以及现代政治经济学论文腔、社会学术语等出戏内容。

**应用场景：** 适用于 `故事/历史报告/` 下所有考据、起义、征伐、变法、朝代更替等历史正文的撰写与审校。
