规则：撰写与修订九州历史报告、王朝兴亡纪事、民变起义及制度沿革考据时，必须严格奉行以下三大核心准则：

1. **司马迁白话文体（文风基准）**：
   - 宗承太史公“究天人之际，通古今之变，成一家之言”之博大胸襟，恪守“不虚美，不隐恶，谓之实录”之史家风骨；
   - 采用**通俗晓畅而苍劲雄浑的白话文**，文字务求简劲有力、气韵沉凝，笔墨重在刻画人物行藏抉择、言辞辞令、时势激荡、利害权变与悲壮宿命。全篇须具起承转合之波澜，严禁沦为干燥枯瘪的文献碎屑罗列；
   - 篇末统一以“太史公曰 / 撰者曰 / 考者曰”作点睛论赞，寓褒贬之义于深沉慨叹之中，融史家独到见解于一家之言。
2. **坚决肃清“口癖与套话”**：
   - 严禁叙述垫字：“后世”（动辄跳出当下时空妄下判词）、“故而”（机械交代因果）、“论及”（说明文批注腔）、“若说”（说书套路假定）；
   - 严禁生硬堆砌器官化词汇：“骨/脉/肉”（如“州骨、工脉、军骨”等生硬组合）；
   - 严禁连用绝对化句式：“最冷/最硬/最怕”。
3. **彻底摒弃现代学术与政论腔调**：
   - 坚决杜绝使用现代社科理论术语，诸如“阶级分析”、“阶级割裂”、“生产力与生产关系”、“剥削剩余”、“纯经济单位”、“总危机”、“系统性崩溃”、“组织度演化”、“历史的吊诡”、“划时代意义”、“证明了如下三点”等现代学术八股架构；
   - 历史演进的根本动力机制，必须全然转化为仙侠世界原生的世态人事利害：灵田赋税沉重、矿丁苦役无休、山川灵脉被大派抽吸枯竭、门阀豪强兼并隐匿、散修黔首流离失所、法网酷烈且失期当斩、天灾频仍与中枢失信等天地人事间的真实痛痒。

**原因：** 用户明确要求历史报告必须宗承司马迁风格之通俗白话，严正指出此前文本中混杂了明显的叙述口癖（后世/故而/论及/若说）以及出戏的现代政治经济学论文八股腔调。

**应用场景：** 适用于 `故事/历史报告/` 目录下所有考据、起义、征伐、变法、朝代更替等历史正文的撰写与审校。
