name: State And Reference Split
description: 州域双文件按“正文为官面舆地总录、参考稿为民间异闻补遗”明确分工，避免内容重叠
type: feedback
---

规则：成对设立的地理设定文档应实施明确的双轨分工：正文优先采用庄重雅正的官修舆地总录与州郡志书口吻，负责奠定疆域梁柱、山川走势、要塞关防、豪强宗门与法度规制；参考稿则侧重收录民间逸闻、海客传闻、野史异志与市井口碑，补足奇幻风物与微观人情，严禁两份文件之间发生大段内容重叠与信息机械复制。

**原因：** 用户明确指出，州域条目采取此类分工更为精妙——官修与民传双轨并立，既能保障地理制度之清晰稳定，又能极大丰富大荒天地的生活层次与神秘韵味。

**应用场景：** 后续处理州域、大荒险境、势力疆界、郡邑通览等双文件结构时，若正文与参考稿并存，统一遵循“官修梁柱 + 民间补遗”的双轨模式组织内容。
