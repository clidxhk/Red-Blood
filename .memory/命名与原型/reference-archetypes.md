规则：涉及因果循环、天地秩序、神魂本质、神明位阶或乾坤运化等宏观世界观核心法则时，必须率先检索传统佛教、道教、中国古代经籍以及世界古老神话中的成熟原型，以此为根基完成仙侠世界内的原生化转译；严禁未经任何文化溯源而凭空生造浅薄机制，更不可将无依据的杜撰伪饰为古老道统。

**原因：** 用户明确要求核心玄幻设定必须具备坚实的文化根底与悠久的历史纵深感，避免凭空生造缺乏沉淀的浮浅概念。

**应用场景：** 新建、重构或扩写世界观核心法理、神话体系、因果架构与超自然秩序时严格落实。
