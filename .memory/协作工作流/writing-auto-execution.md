---
name: Writing Auto Execution
description: 面对小说正文创作与叙事扩写任务，智能体可自主决策并直接执笔，无须逐次提交审批
type: feedback
---

规则：面对长篇仙侠小说正文创作（例如《炎帝崛起》正文撰写）或长篇叙事扩写任务时，智能体可自主进行全局统筹与情节决策，直接进入正文执笔撰写流程，无须每次都预先生成 Implementation Plan 等待用户逐轮审批。

**原因：** 避免频繁的前置审批阻断用户的长篇阅读连贯性与创作节奏，显著提升创作推进效率。

**应用场景：** 小说各卷正文编写、章回体叙事深描与长线剧情梗概扩写。
