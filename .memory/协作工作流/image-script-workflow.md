name: Image Script Workflow
description: 图像生成与插图排版统一复用既定脚本流程，省去重复排查环境与参数调用
type: feedback
---

规则：为各类设定条目生成并插入图像时，统一依循固化的脚本流程执行：
1. **前置考据**：检索目标条目及同类条目既有的插图位置、构图风格与画面意境要求；
2. **脚本参数规范**：研读 `scripts/generate_image_from_md.py` 的当前逻辑，确认脚本已自动从 `scripts/.env` 读取 API key、base URL 与 image model。执行脚本时仅须传入 Markdown 目标路径、额外画面补充说明（`--extra`）、尺寸比例、画质与输出目录，严禁重复手工配置或手动传入 key、model 等环境变量；
3. **审图与排版**：生成完毕后严格审视图像是否高度切合条目神韵；随后将选定之首张成果文件更名为与条目同名的 `.png` 格式，依该类文档既定版式插入正文适宜段落。若画面意象有偏差，优先通过优化 `--extra` 参数中的画面微观描摹再次执行，切勿无谓地排查执行环境。

**原因：** 用户要求将图像生成脚本之标准调用范式固化沉淀，避免后续每次处理图像任务时重复探索取参、审图和插图流程。

**应用场景：** 当用户要求为人物、器物、宗门、州域、绝地、场景等任何设定条目生成图像并插回对应 Markdown 正文时严格遵守。
