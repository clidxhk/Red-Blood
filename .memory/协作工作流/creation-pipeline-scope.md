---
name: creation-pipeline-scope
description: 日常任务主代理直接完成，创作与明确的正式内容专项审校才调用管线子代理
type: feedback
---

日常问答、查询、提交与进展查看、素材流程评估和改进建议、规则与记忆维护、脚本开发及 Git 操作，由主代理直接完成，不调用创作管线子代理。正式设定或故事正文的创作保留完整管线；用户明确要求正式内容专项审校时只调度对应角色，明确要求委派时按指定范围执行。混合任务只在实际进入创作或专项审校的部分启用管线。

**原因：** 用户指出非创作的日常任务也被套入管线，要求收窄调度范围，避免无关调用。

**应用场景：** 每轮先按交付目标判断任务类型，不以提到小说、世界观、人物或涉及多个文件作为调用依据；单纯查看经典小说取材情况并提出改进建议仍属日常分析。
