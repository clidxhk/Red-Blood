规则：接收到创作设定、条目或世界观任务时，必须率先全面检索仓库内是否已存在相关条目、提及线索或上下文依据，并在既有内容基础上展开严谨扩写；严禁未经查证便凭空即兴编造。凡触及历史时间线、势力登场先后、源流归属及地理疆界时，必须严格核验核心事实，切忌将外部通俗修仙套路未经转译直接套入当前世界观。若模型执行不稳定，应直接在 Agent 系统规约中强化约束，将“先检索、再提炼、后落笔”固化为刚性禁令与流程步序，不可仅依赖模型自觉领会。

**原因：** 用户明确要求“布置任务时必须首先检索有无关联内容，决不可未经查证即刻凭空臆造，每一次创作都必须师出有名、皆有依据”，并进一步批示“若执行仍有偏差即表明约束力度不足，须直接修改 Agent 规约以加强硬性制约”；在重修神族条目时，亦再三强调“神族系章皇末年方自界外降临，切不可遗忘此类核心先决前提而盲目下笔”。

**应用场景：** 新增或扩写人物、势力、地理、神话、功法体系、器物宝物等一切创作任务之前，必须率先完成仓库检索与上下文研读，方可定夺写法、落脚点与交叉引用；若发现子代理经常跳过检索阶段，优先强化代理规则本身。

补充说明：检索先行原则已固化为根目录 `AGENTS.md` 阶段一 `research-agent` 强制管线（所有任务必经阶段），本记忆完整保留用户纠正的原由以及“约束不足时直接硬化规则”的处理方式。
