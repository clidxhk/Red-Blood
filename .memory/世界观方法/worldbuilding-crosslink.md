规则一：全仓库所有 `[[...]]` 交叉引用都必须严格照仓库实际文件名书写，不得擅自改字、补空格、换标点或调整编号格式；例如应写 `[[11.茶馆闲聊·火楼]]`，不可写成 `[[11. 茶馆闲聊·火楼]]`。

规则二：撰写或扩写世界观、传说、人物、体系条目时，不只新增单篇内容；应同时为相关旧条目补充交叉链接，必要时回改相邻文本以维持设定前后连贯。

**原因：** 用户明确要求所有交叉引用名与真实文件名完全一致，避免 Agent 自作主张改格式，造成链接失配、风格混乱和仓库命名不统一；又要求"在其它内容中增加和它相关的链接，也可以修改相关内容，保持连贯"。

**应用场景：** 新写、改写、回填任何含 `[[...]]` 的正文与说明文件时，先核对文件名再落笔；新增条目时优先检查上下游文件是否需要导航链接、正文提及或少量衔接性改写。文件名精确匹配已写入 AGENTS.md 交叉引用原则与 crosslink-checker 检查项，本记忆保留纠正原因与补链回改的连贯性要求。
