description: 人物现任职司须单线稳定，多元阅历归入过往履历或兼管事务，杜绝身份飘移割裂
type: feedback
---

规则：同一人物跨文档反复登场时，必须先确立一条清晰稳定的主导身份或现任职司，并在所有场景描写中保持一致。若该角色在世态中确实涉足多方门道，仅可将其写为过往履历、兼涉杂务、经手账目或熟稔之行当门径，严禁在不同篇章中随意以数种并列的现任身份轮番替换。

**原因：** 用户明确指出，程衡生在不同篇章中被分别描述为药栈账房、海货栈掌柜、跑海埠营生之人，导致角色主体身份混乱，其人脉关系网与临场发言的分寸亦随之失准飘移。

**应用场景：** 新建人物、回填无名角色、扩写人物双文件、批量修订茶馆闲聊入席介绍或其他群像场景时严格恪守；须先行统一人物的当前主干身份，再将其余行业接触面降格为过往经验与经手见闻。
