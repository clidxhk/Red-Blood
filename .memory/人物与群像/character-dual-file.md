规则一：常规人物条目的新建、扩写或改写，必须同时交付 Markdown 正文与 JSON 底谱，不得只写人物正文。Markdown 主文默认覆盖概述、核心设定、身世行历、修行能力、关系位置、余响六类内容；JSON 底谱默认沉淀 identity、presence、turning_points、methods、relations、motifs、writing_hooks 等稳定结构，用于承载稳定字段、关系索引、能力边界与可复用细节。

规则二："异类"条目（含灵兽、器灵、妖魔等）默认只写正文，不同步构建人物 JSON 底谱，除非用户另行要求，以免异类条目被人物结构约束得过重。

**原因：** 用户认为人物写成 md 更适合阅读与沉浸，json 更适合表现人物各方面细节，希望两者结合固定下来；后续进一步明确异类不按常规人物处理，不需要构建人物底谱。

**应用场景：** 编写角色小传、人物卡、阵营核心成员档案，批量扩写人物或统一角色卡格式时，默认采用 md 主文 + json 底谱的双层结构；处理异类条目时不生成底谱。双文件要求已写入 AGENTS.md 人物双文件规则与 crosslink-checker 检查项，本记忆保留分工细节与异类例外。
