---
name: character-dual-file
description: 人物条目统一采取 Markdown 正文与 JSON 底谱双轨并行；异类条目默认只撰写正文
type: feedback
---

规则一：常规人物条目的新建、扩写或重修，必须严格落实 Markdown 叙事正文与 JSON 结构底谱双文件交付，严禁仅撰写正文而遗漏底谱。Markdown 正文默认覆盖概述气象、核心设定、身世因果、修行威能、人际网络与余韵传闻六大板块；JSON 底谱则沉淀基础人口信息、形相印记、关键转折、标志法门、关系纽带与创作伏笔等稳定结构，为后续长篇调用提供标准化索引基准。

规则二：“异类”条目（涵盖神兽遗种、法宝器灵、太古妖魔等）默认仅撰写 Markdown 正文，不同步构建人物 JSON 底谱（除非用户明确专项要求），以免异类条目被拟人化的人格结构过度约束。

**原因：** 用户指出，人物以 Markdown 呈现更利于文字浸润与阅读体验，而以 JSON 沉淀则更利于精准表现人物的多维结构与边界约束，要求两者有机结合并固化为铁律；后续进一步裁定，异类条目因本源特殊，不按常规人物处理，免建底层人物卡。

**应用场景：** 编写人物小传、角色卡片、阵营核心元勋档案，或批量扩写群像时，默认采用双文件架构；处理异类条目时则免建底谱。双文件铁律已完整写入根目录 `AGENTS.md` 人物规范与 `crosslink-checker` 核心审查项。
