name: avoid-catchphrase-repetition
description: 严厉管控高频词根、套话与叙述垫字口癖，杜绝“骨/脉/肉”、“最冷/最硬/最怕”、“后世/故而/论及/若说”及“旧X造词/万能压动词”等机械重复
type: feedback
---

规则：撰写、扩写与重修文本时，必须主动防范模式化口癖，对以下四类高频套话、转折垫字及单字惯性实施刚性管控并予以替换：

1. **叙述垫字与转折口癖（重点排查）**：
   - **“后世”**：严禁动辄跳脱当前时空、以上帝视角或编年通史妄下断言（如“后世记为……”、“后世修士以为……”、“后世将其称为……”）。除特定史料考据体（如伪史引文注疏）外，叙事必须紧扣当前时空，或以世界内具体传承（如“某派谱录”、“某宗注疏”）替代泛滥空洞的“后世”；
   - **“故而”**：严禁作为万能连词频繁滥用。杜绝段段以“故而”机械连接因果，改用意合承接、行动驱动或事实递进自然推进；
   - **“论及”**：严禁带入说明文或论文批注式解说腔（如“论及杀伐手段……”、“若论及某某……”）。须将特质融汇进具体事实、交锋实录与感官细节之中，杜绝横向盘点式的干瘪论调；
   - **“若说”**：严控说书腔式的刻板假定与生硬对比（如“若说前朝……那么……”）。摒弃套路化铺垫，直接落笔陈述事实。
2. **生硬意象与词根口癖**：严加警惕同一批意象词在近距离内密集回响，尤须戒绝生硬拼接“骨、脉、肉”等器官化词汇（如“州骨、工脉、兵骨”等机械组合）。
3. **绝对化句式套话**：彻底杜绝“最冷、最硬、最怕”等绝对化排比句式。
4. **单字造词与万能动词口癖**：
   - **“旧X”造词堆积**：排查“旧法/旧例/旧路/旧规/旧名/旧档”等机械组合。换写方向：故X、昔X、前朝、宿X、残X、老X、祖上、早年，或依上下文径直删去“旧”字（如“旧档未载”改“档册未载”）；
   - **万能“压”字滥用**：警惕顺手滥用“压住/压着/压在/压得/压到底”。依据具体语境合理分流替换：物理按住改用“按/扣/抵”，笼罩覆压改用“笼/罩/覆”，沉重之势改用“沉/坠”，强力制衡改用“镇/慑/扼/逼”，克制收敛改用“放低/敛/咽/掖”，挤迫催逼改用“碾/欺/勒”；
   - **保护例外（切勿误伤）**：`[[ ]]` 引用内专有名词（如“偏街旧茶馆”、“旧星辉决”、“旧契·摩律”及回目名）、词化固定词汇（如“依旧/仍旧/照旧/陈旧”）、特定宗门术语（如教义法条语境下的“灵压/镇压”）、行业行话（如“压库/压舱/压箱底/压价”适度保留）、以及出场角色固定身份标签（如“北府旧军汉/落魄旧文人”）；
   - **执行指标**：任一自然段内非保护性同字出现不超过一处；重点篇章主导字降幅达 40%–55%，次要篇章着力拆解段内密集聚集，不搞机械一刀切。

若某种修辞或意象已在同篇或相邻条目中形成明显回声，必须果断变换句法、意象与叙述切入点，防止文本被狭隘的少数词汇所困囿。

**原因：** 用户多次指出仓库存在严重口癖化倾向——早期有“骨/脉/肉”与“最冷/最硬/最怕”套话，继而出现“后世、故而、论及、若说”垫字，近期又指出“旧”、“压”二字已成下意识滥用的口癖。机械重复造成严重的行文模式化与阅读疲劳，极大削弱了文本的历史厚度与文学品质。

**应用场景：** 适用于所有世界观正文、人物、地理、势力、器物、历史与场景类文本的撰写（`style-writer`）与语气审校（`tone-checker`）；已全面固化入 `AGENTS.md` 撰写禁令、`style-writer.toml` 口癖管控节及 `tone-checker.toml` 审查项。
