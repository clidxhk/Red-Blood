name: proofread-clarity-and-dedup
description: 全面清理半白话、语病残句与设定漂移，确保前后因果自洽且表达畅达
type: feedback
---

规则：每次完成设定撰写、扩写、重修或回填之后，必须逐段通读全部增改内容，严密落实以下审查标准：
1. **行文畅达与除病去涩**：语言必须自然严谨、文理通顺、逻辑缜密，具备纯正雅致的中文底色，彻底剔除故作深奥的半生不熟半白话，严禁出现病句、断烂残句与含混代词；
2. **精炼除重**：主动筛除并在文字层面重构重复的意象、机械复述的设定以及重叠的段落含义；
3. **触及旧文顺带清理**：在检索、改写与旧文回填时，凡属本次触及范围内的既有段落，若存在半白话、句义断裂或阅读滞涩等问题，必须顺道修润清理，严禁对难读旧文视若无睹；
4. **恪守概念一致性**：严禁设定前后漂移。若前文仅属修辞比喻、局部异象或感官侧写，后文绝不可在未予交待的情况下直接偷换为实体事实或全局定论，防止前后矛盾或造成荒诞突兀的惊悚感。

凡读来滞涩、逻辑跳脱、语意不清或同一意涵机械连说数遍之文本，严禁直接交付，必须修葺至朗朗上口方可放行。

**原因：** 用户明确要求“遇到半白话与读不懂的内容必须开始修改清理”，并特别强调严禁出现“前文叙述为某种意象、后文偷换为实质定义”的现象（例如将建筑长出肉质的局部异象，写着写着演变为整座城池全由血肉构成），此种设定漂移极度破坏逻辑自洽与阅读体验。

**应用场景：** 适用于一切仙侠设定文档（人物、势力、功法、器物、历史、场景、总纲等）；尤其在大篇幅扩写、融合式重构或引链回填之后，必须全篇自检校对，重点根除故弄玄虚的残句、含混指代、概念偷换与机械重述。
