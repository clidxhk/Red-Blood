天地底层律是形脉与意脉的**实时对流**：形为体、意为魂，时时有取有还，不记账、不存档。意脉长期只取不还，或以强序压过天然形脉，即成"失当"；失当当下即留痕并持续累积。单点失当可被[[帝网]]吸收、分散、转嫁，但一旦累积越过网的承受能力，便沿同一张网一并剧烈回流——这种集中反冲即"业"。

术语重映射：业因＝失当之举；业痕＝当下即成的形意分布变形（实时，非封存）；业果＝越过阈值后的集中回流。

**原因：** 用户指出原"业＝延后兑付的账"不符合九州"时时刻刻变化"的时间观。业应是形意失衡积到阈值时的反冲，而非被推迟的清算；"延迟"其实只是阈值错觉。

**应用场景：** 所有涉及业、形意、帝网、修士境界、神裔重数、九州与神族之别的正文改写与新增。写作要点：①"业果先显于高位"须写成结构性牵连（身在最深、最先失稳），不是道德报应；②神族之误应写成"把失当的实时变形误读为可延后结算的账"（[[烬序·白傀]]只能转嫁载荷、不能取消阈值）；③九州看得见实时变化，神族坚持记账，这是两文明最深的岔口。
