# 炽（炎皇）宿命身份设定

## 核心事实与设定规则

*   **天生圣脉与丹田碎裂**：炽天生圣脉，承载着九州大地对[[7.律皇]]绝对铁律与高压统治的自我反冲（天地回流），注定是第八纪的主火。
*   **跨越时空的扼杀**：律皇时期的[[帝阙]]中枢通过玄黄大算轨，跨越时间与空间的界限，估算到了炽在未来的诞生与威胁。帝阙下达敕令，施展无上仙法，在炽出生的那一刻，强行将他的丹田彻底震碎，使之沦为无法聚气的废体。
*   **市井实用主义**：因为修行之路在起点被掐断，炽在渡口、赌肆酒肆的市井泥潭中长大，养成了极端务实、反权威的“市井实用主义”。这种不受任何仙门包袱和陈规约束的实用主义，成为他打破一切修仙界陈规的最强武器。
*   **凡人生机**：他坚信天道不该只庇护高高在上的仙人，更要为天下凡人留一线生机。

## 应用场景

在编写任何与[[8.炎皇]]（炽）相关的历史、故事或设定时，必须贯彻以下原则：
1.  他无法通过吸纳灵气的方式聚气修行，他调动力量依赖的是自身圣脉对十三州地脉的直接共鸣与底层人道气运。
2.  强调他不信天命、只信自己的务实性格，他的招式没有仙门章法，极重实用。
3.  他与[[7.律皇]]之间是跨越时空的宿命宿敌，在言行和思想上体现出对律法禁锢的强烈反叛。
