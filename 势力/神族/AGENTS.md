# 神族条目写作规范（势力/神族目录）

本规范适用于 `势力/神族/` 目录树下全部条目（神族势力总纲、传说、家族、机构等）。全仓库通用的文件结构、交叉引用、标签规则见仓库根目录的 `AGENTS.md`，本文件只写神族类别的增量约束。

## 起源叙事双层口径（强制，不得再裁决）

神族起源叙事采用**双层口径**：「后世正典/史书追封」与「更早残卷直书」并存，两套说法都是设定的一部分。

- 后世史书称九主神为「九座副座」；更早残卷直书他们是「从不同塔、不同殖民点被带上舟的九名奴隶」。
- 诸主神条目里的镜穹职衔（农政大臣、水文监测官、主管祭司、首席军帅、锻炉大师、平码官、图书馆馆长等）属「史书粉饰层」。

必须遵守：

1. 不得据镜穹职衔把九主神出身改写成否定奴隶出身的单层说法。
2. 也不得反过来删去职衔——粉饰层本身就是设定的一部分，"史书如何追封"是世界内事实。
3. 凡写主神出身、骨舟漂流序列、初誓文本、"倒海大洪"前后时间线，先按双层口径调和既有异说；回填时优先改主神条目侧，不动已定稿的《倒海大洪》《起源总纲》正典。
4. 部分主神条目位于 `巨头/主神/` 目录，不在本目录树下；该处任务由根 `AGENTS.md` 阶段一的附带规则补足，写主神出身相关内容时同样遵循本节。
