# 神族条目写作规范（势力/神族目录）

本规范适用于 `势力/神族/` 目录树下全部条目（神族势力总纲、传说、家族、机构等）。全仓库通用的文件结构、交叉引用与标签规则详见根目录 `AGENTS.md`，本文件专门确立神族类别的增量专属约束与法理基准。

## 起源叙事双层口径（强制基准，不可偏废）

神族起源叙事统一确立为**双层口径**：「后世正典/史书追封」与「更早残卷直书」一体并存，两套语境皆为世界观不可分割之有机组成：

- **史书追封层**：后世正典史册尊称九主神为「九座副座」，将其冠以镜穹文明时期的崇高职衔（农政大臣、水文监测官、主管祭司、首席军帅、锻炉大师、平码官、图书馆馆长等），此属统治确立后的神圣粉饰；
- **残卷直书层**：更早之大荒残卷则直言不讳，揭示九主神实为「从不同高塔、不同殖民聚落被强行押送登舟的九名卑微奴隶」。

撰写神族起源相关内容时，必须严格恪守以下四项准则：

1. **严禁片面化改写**：不得因存在镜穹职衔便将九主神出身改写为单一的高贵法统，进而否定其奴隶出身之历史真实。
2. **严禁删削粉饰层**：亦不得因强调奴隶出身而径直抹去其官僚职衔——粉饰层本身即是世界内统治演进的事实，“史书如何步步追封造神”乃是世界观不可或缺的制度肌理。
3. **回填与调和原则**：凡触及主神出身、天弧漂流序列、初誓文本以及“倒海大洪”前后编年，必须先行运用双层口径调和既有异说；实施交叉回填时，优先修润主神个体条目，切勿撼动已定稿之《倒海大洪》与《起源总纲》正典核心。
4. **跨目录协同效力**：部分主神条目收录于 `巨头/主神/` 目录，虽脱离本目录树，但根目录 `AGENTS.md` 阶段一已明确要求此类任务必须附带本文件，凡涉及主神起源叙事，必须无条件遵循本节规范。
