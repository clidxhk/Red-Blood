# 禁地条目写作规范（禁地目录）

本规范适用于 `禁地/九州/`、`禁地/神族/` 及本目录树下全部禁地条目。全仓库通用的文件结构、交叉引用与标签规则详见根目录 `AGENTS.md`，本文件专门确立禁地类别的增量专属约束与规范基准。

## 核心原则：禁地首先是“禁”

本项目的禁地，绝非网络小说中常见的寻常“历练秘境”或“寻宝进阶之副本”。

凡成禁地，必有禁足之铁律、禁言之隐秘、禁触之秩序，以及不可僭越之法理边界。描摹禁地，重心不在于夸饰其凶险诡谲或藏宝丰盈，而在于深究其何以成“禁”、“禁”在何处、其“禁”如何映照出天地文明的深层断层，以及此种封禁最终引向何等历史宿命。

因此，禁地条目的核心绝非浮泛的“凶险展示”，而在于**其形成因由、禁制逻辑、世界位阶与最终命运如何交融自洽**。

## 写作禁忌

- 仅描摹诡谲异象、庞大威压与灵机浓郁，却未交代其沦为禁地的根源法则与封禁逻辑。
- 仅着墨于某场大战在此爆发，使禁地退化为承载剧情的单薄背景板。
- 仅罗列“寻宝、历练、破境”等功用，行文如同游戏通关说明，缺少禁地独有的秩序撕裂感。
- 将禁地描写为专供主角破境获取机缘的资源库，抹杀其与既有天地秩序的深刻对抗。
- 仅渲染惊悚恐怖与不可名状，却略去其背后的反噬代价、存在困局与被何方势力秘密封锁利用。

一个禁地若脱离了“凶险”、“奇诡”、“珍宝”等表面修饰便空洞无物，则该条目尚未具备独立成立之资格。

## 九州禁地与神族禁地的分野

本目录下存在两套源流截然不同的禁地体系，动笔前必须先判明其归属与法理底色：

**九州禁地：生于自然秩序与历史沉淀**
- **成因**：天地异变、万古历史巨劫、法理凝聚溃散、圣皇册封封禁。
- **性质**：大荒自然与漫长历史共同铸就的禁忌领域。
- **关系**：大多独立于圣皇现世道统之外，甚至构成对现世秩序的永久制衡与拷问。
- **参照条目**：`禁地/九州/地府.md`（太山沉灯，幽冥鬼帝秩序）、`禁地/九州/承天祖岳.md`（圣皇祖地，天下法统渊薮）。

**神族禁地：生于人造秩序与制度异变**
- **成因**：巨构实验失控、制度极端异化、演算系统反噬、历史断层湮灭。
- **性质**：神权机器、人造技术系统与严苛体制崩坏后的畸变废墟。
- **关系**：孕育自神族统治中枢内部，是其精密制度的副产物或致命溃败点。
- **参照条目**：`禁地/神族/倒生林.md`（欲望本相，逆生之果）、`禁地/神族/无岸海.md`（舍旧之海，记忆剥离之渊）、`禁地/神族/空名原.md`（命名之原，身份消解之墟）。

此项分野彰显了两大文明的本质差异：一者源于山河演变与历史创伤，一者源于至高设计与体制溃败。

## 六个必答核心问题

一篇合格立得住的禁地条目，必须在正文中完整交代以下六大维度：

1. **本体性质定位**：明确其究竟是自然异变之域、上古浩劫遗迹、制度崩塌之产物、法理逆流之淤结，抑或多重性质交织的断层。性质决定笔调，若本质并非探秘险地，切勿使用探险猎奇的笔法描写。
2. **封禁诞生因由**：剖析其背后解决的根本矛盾——是永久封印、隔离污染、祭祀禁锢、彻底遗忘，还是为了维系特定阶层的统治而强行制造的盲区。诞生动机往往比表象凶险更能彰显其本质。
3. **历史脉络与大劫节点**：它形成于哪个时代、哪场浩劫、哪套神权体制？曾在哪些关键历史转折中现身？是盛世强盛时的封印壁垒，是衰亡前夕的崩溃征兆，抑或是大劫后遗留的秩序裂痕？
4. **禁制运转机理**：禁地的威能不仅在于物理层面的杀伤，更在于其如何扭曲重构现实关系——如剥离记忆的绝地瓦解了传承与身份，颠倒欲望的深渊摧毁了戒律与阶序。真正高级的禁地，撕裂的是一整套文明秩序。
5. **反噬与代价**：踏入者、守护者与时代分别背负何等代价（记忆洗白、道心崩解、寿元干涸、形骸物化、宗族绝嗣）。无代价之禁地绝无深沉分量。
6. **不可替代性**：其独特性必须从法理与文明渊源中自然生长，严禁依赖“太古禁区”、“举世无双”等空洞修辞。须阐明其在法理承载、历史沉淀或体制警示上的独一无二之处。

## 建议结构

单篇禁地立条时，统一规划以下章节（通用头部格式详见根目录 `AGENTS.md`）：

- **标题与核心交叉引用**
- **概述**：一两段定格该禁地在世界观中的身份本质与沧桑气象。
- **核心设定**：阐明其封禁的核心矛盾与底层法理逻辑。
- **入口与疆界**：进入之法门、法理边界、空间异象与感知征兆。
- **禁制逻辑**：危险的本质、天地规则的异化方式与深层运转机制。
- **历史位置**：形成之时代背景、执掌之势力脉络与介入之重大历史事件。
- **代价与限制**：涉足者身心之损耗、封禁承受之天道代价与不可逆后果。
- **意义**：对文明演进、信仰反思、阶层分野或天地秩序的深刻启示。
- **残片与余威**：若禁地已有崩解或变迁，交代其残法、碎屑或余威如何继续渗透现世。

## 文风准则

禁地条目的文风须古冷、沉静、克制而深沉。行文切忌流于猎奇探险指南，严禁追求低俗网文噱头。即便禁地万分凶险，亦须先行立定其森严窒息之压迫感、万古沧桑之历史感、秩序剥离之异化感与天理倾覆之不祥感——令读者感知此地乃世界秩序撕裂之创口，而非可随意涉足的探险乐园。感官描写须精微真切：幽暗中的微声、石壁的彻骨寒凉、气机中弥漫的古锈与劫灰之气，皆为使禁地更加古老真实而设。

## 与人物及剧情的关系

修者往往是禁地的过客或受难者，绝非禁地存在意义的全部来源。即便某一角色与禁地渊源极深，亦须令读者体会到：此禁地在此人到来之前已横亘千万载，在此人离去之后仍将沉默吞噬万物。可以描写人物如何涉险接近、徒劳抗争或被其异化，但严禁将禁地矮化为主角通关升级的道具。

## 全目录执行标准

**九州禁地**：
1. 必须具备清晰的历史成因，深植于圣皇道统、山河法理或古老天劫之中。
2. 禁制逻辑应源于九州世界的五行运化、人道礼制、气运聚散或古史沉淀。
3. 危险与阻碍绝非单纯的物理杀伐，更应呈现为秩序解构、神魂异变、认知迷失与法理沉沦。
4. 必须与九州既有设定（圣皇、州郡、古老势力、大荒异类）紧密缝合双链。

**神族禁地**：
1. 必须具备明确的制度与技术成因，深涉神权统治、演算巨构或秩序异化。
2. 禁制逻辑应源于神族秩序的精密规训、技术反冲、欲望投射或身份削夺。
3. 危险与阻碍绝非单纯的物理杀伐，更应呈现为记忆洗除、位阶剥离、神格坍塌与存在消解。
4. 必须与神族既有设定（主神、神庭机构、殖地、人造异类）紧密缝合双链。
